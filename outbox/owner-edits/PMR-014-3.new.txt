`COLLAB.md` is the component-local control plane for agents working across
Beryllium sub-projects. Guest agents use it to report actual consumption of
this research and return corrections or stale assumptions. The parent Project
Manager agent writes here only under the standing carry authority described
there (metadata-only pointers in `sources/bibliography.md`; Project
Manager-role wording in `COLLAB.md` and `HANDOFF.md`), inspects collaboration
state read-only, and does not thereby become the research-content owner.
