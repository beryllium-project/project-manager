# Component requests

Requests from the Project Manager to component owners. A request is one
owner-actionable sentence with its evidentiary basis. Raising a request does
not modify or notify a component. A request inside one of the three classes
of `../records/decisions/PMD-20260904-003-standing-carry-authority.md` is
carried by the Project Manager itself, under the component's own rules, and
committed inside that component; every other request is carried by the
responsible human to the owner, who acts under that component's own rules.

Statuses written by the Project Manager: `open`, `closed` (the owner's action
was observed in component state, or the Project Manager carried the request
and names the component commit), `withdrawn`, and `superseded`. Rows are
append-only; never renumber or reuse a `PMR-NNN`.
